# Guida Utente - AuraOS

Benvenuto in **AuraOS**, il sistema operativo educativo e intuitivo!

## Primo Avvio

1. **Boot**: All'accensione, vedrai il menu di GRUB con il tema AuraOS
2. **Selezione**: Premi INVIO per avviare AuraOS (o attendi 5 secondi)
3. **Autologin**: Verrai automaticamente autenticato come utente `auraos`
4. **Desktop**: Si aprirà automaticamente AuraOS Desktop in Chromium

## Navigazione

### Menu Start
- Clicca sull'icona **"Applicazioni"** nel dock in basso
- Oppure clicca su **"Attività"** nella barra superiore

### Finestre
- **Sposta**: Trascina la barra del titolo
- **Ridimensiona**: Trascina gli angoli o i bordi
- **Chiudi**: Clicca la X rossa in alto a destra
- **Minimizza**: Clicca il trattino (-)
- **Massimizza**: Clicca il quadrato (□)

### Launcher
- Premi il tasto **Windows** o clicca su **"Applicazioni"**
- Digita per cercare app, file o impostazioni
- Usa le categorie: Tutto, App, File, Impostazioni

## Applicazioni

### File Manager
- Naviga tra cartelle e file
- Crea nuove cartelle e file
- Rinomina, copia, sposta file
- Cestino con ripristino

### Terminale
- Comandi base: `ls`, `cd`, `mkdir`, `rm`, `cp`, `mv`
- Comandi avanzati: `find`, `grep`, `tree`, `cat`, `echo`
- Aiuto: digita `help` o `man <comando>`

### Browser
- Naviga nel web
- Cronologia e preferiti
- Download manager

### Tutor AI
- Chiedi aiuto su qualsiasi funzione
- Tutorial interattivi
- Suggerimenti contestuali

### Impostazioni
- Cambia sfondo desktop
- Modifica tema (chiaro/scuro/auto)
- Cambia dimensione dock e font
- Attiva/disattiva effetti sonori
- Imposta password di accesso

## Tips & Tricks

- **Spazi di lavoro**: Usa gli spazi di lavoro per organizzare le finestre
- **Ricerca veloce**: Usa il launcher per trovare tutto velocemente
- **Widget**: Clicca sull'orologio per vedere il calendario
- **Notifiche**: Clicca sull'icona campana nella barra superiore

## Risoluzione Problemi

### Il desktop non si carica
- Riavvia il sistema
- Prova la modalità "Safe Mode" da GRUB

### Audio non funziona
- Verifica le impostazioni audio nel pannello di controllo
- Prova a riavviare il servizio audio

### Rete non funziona
- Verifica che il cavo Ethernet sia connesso
- Configura il WiFi dalle impostazioni di rete

### Prestazioni lente
- Chiudi le app non utilizzate
- Prova la modalità "Text Mode" se la grafica è lenta
