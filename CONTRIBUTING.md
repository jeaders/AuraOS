# Contributi

Grazie per il tuo interesse in AuraOS! Ecco come contribuire.

## Come contribuire

1. Fork del repository
2. Crea un branch: `git checkout -b feature/nome-feature`
3. Commit delle modifiche: `git commit -m 'Aggiunge feature X'`
4. Push: `git push origin feature/nome-feature`
5. Apri una Pull Request

## Regole

- Segui lo stile di codice esistente
- Commenta il codice complesso
- Aggiorna la documentazione se necessario
- Testa le modifiche prima del push

## Struttura

- `js/app.js` - Core OS, window manager, apps
- `js/ai/tutor.js` - Tutor AI
- `css/style.css` - Stili
- `docs/` - Documentazione e piano di implementazione
