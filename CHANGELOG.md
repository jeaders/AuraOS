# Changelog

All notable changes to AuraOS will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-21

### Added
- Initial release of AuraOS
- Linux 6.1 kernel with AuraOS branding
- GRUB 2 bootloader with custom theme
- Debian Bookworm root filesystem
- Chromium kiosk mode for web-based desktop
- LightDM display manager with autologin
- AuraOS desktop environment (HTML/CSS/JS)
- File Manager with virtual filesystem
- Terminal emulator
- Browser (Chromium-based)
- Tutor AI (Italian)
- Gallery app
- Music player
- Calculator
- Notepad
- Settings app
- Task Manager
- Guide app
- Games
- Boot screen with profile selection
- Login screen with password protection
- Desktop widgets (clock, calendar)
- Notification system
- Global launcher/search
- Sound effects
- Animated wallpapers
- Multi-workspace support
- Window management (drag, resize, snap)
- File System Access API integration
- PWA support (manifest, service worker)
- Electron wrapper for desktop deployment
- Build system for ISO creation
- Documentation (kernel, grub, filesystem, build)
- GitHub Actions CI/CD
- MIT License

### Changed
- Project renamed from JeadOS to AuraOS
- All code references updated to AuraOS branding

### Fixed
- Initial release, no fixes yet
